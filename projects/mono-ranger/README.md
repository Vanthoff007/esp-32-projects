# Mono Ranger

Object-distance estimation from a single camera on an ESP32-S3.

**Status:** research phase. There's no firmware yet. This folder holds the feasibility
survey that decides which approach to build.

## What's here

| Path | Contents |
| --- | --- |
| [`report.html`](report.html) | Full survey *Monocular object-distance estimation on an ESP32-S3*: fundamentals, ranked approaches, edge-deployment feasibility (ESP32-S3, Raspberry Pi, Jetson), proposed architectures, validation plan, risks and references. Open it in a browser. |
| `assets/charts/` | Charts used in the report (SVG + PNG), generated by the script below |
| `assets/diagrams/` | Geometry figures (SVG) and architecture / pipeline diagrams (Mermaid `.mmd`) |
| `scripts/make_figures.py` | Regenerates every chart in `assets/charts/` |

The charts show published figures or explicit error models and engineering estimates.
None of them are measurements from this project's hardware yet.

## Regenerate the charts

From this folder:

```powershell
uv run --with numpy --with matplotlib python scripts/make_figures.py
```

## Next steps

Pick an architecture from the report's recommendations, then add the ESP-IDF project here
(`CMakeLists.txt`, `main/`, `sdkconfig.defaults`) following the repository's
[Adding a new project](../../README.md#adding-a-new-project) guide.
